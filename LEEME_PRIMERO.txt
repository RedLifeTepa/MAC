1. Firebase > Authentication: conserva tu cuenta y contraseña actuales.
   Comprueba que Correo/Contraseña esté habilitado.

2. Firebase > Firestore Database: crea la base (default) si aún no existe.
   Puedes usar Spark dentro de sus cuotas. No actives Functions.

3. Firestore > Reglas: reemplaza TODO por REGLAS_FIRESTORE.txt y PUBLICA.
   No dejes reglas abiertas.

4. Authentication > Users: copia el UID de tu cuenta.
   Firestore > Datos: crea la colección users y un documento con ESE UID.
   El ID NO es el correo ni un ID automático.

   Campos del documento:
   name         string     Bryan Delgadillo
   email        string     redlifetepa@gmail.com
   role         string     admin
   active       boolean    true
   openShiftId  null       null

   No escribas true como texto. No guardes la contraseña en Firestore.

5. Reemplaza los archivos de tu repositorio por esta versión completa.
   GitHub > Settings > Pages > Source: GitHub Actions.
   El workflow publica web/ cuando haces push a main.
   Autoriza TU-USUARIO.github.io en Authentication > Authorized domains.
   Espera la publicación en verde y recarga con Ctrl+F5.
