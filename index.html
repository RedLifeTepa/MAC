¿Cómo conectar tu proyecto Firebase en 10 segundos?

1. Copia el bloque const firebaseConfig = { ... } o el JSON de tu proyecto desde Firebase Console.

2. Pégalo abajo y haz clic en "Conectar y Sincronizar con Firebase Cloud".

3. El sistema cargará los módulos oficiales de firebase/app, firebase/auth y firebase/firestore y subirá tu inventario base a tu nube.
